# C语言程序设计教学仓库

这是一个面向C语言初学者的完整教学仓库，提供从第一行程序到文件操作的讲授课件、上机任务、练习题和章节例程。内容适合课堂学习、课后复习及自主练习。

## 学生快速开始

1. 按照[环境配置教程](环境配置/README.md)安装GNU GCC和VS Code C/C++扩展。
2. 从[讲授课索引](课件/讲授/README.md)选择当前章节，直接在浏览器中打开对应`index.html`。
3. 进入[题库](题库/README.md)独立作答，再展开参考答案与解析。
4. 从[例程库](例程/README.md)选择程序，在仓库根目录编译运行。

例如，在Windows PowerShell中运行第一个程序：

```powershell
gcc "例程/chapters/01-programming-and-c/ex_c01_001_1_1.c" -o hello.exe
.\hello.exe
```

macOS和Linux将输出文件名改为`hello`，并使用`./hello`运行。

## 学习建议

- 先阅读课件中的规则和示例，再完成同页练习。
- 题库练习先独立作答，然后查看解析并重新运行相关程序。
- 上机任务先按实验步骤完成程序和测试，再翻页对照参考程序。
- 遇到旧语法或平台接口时，阅读例程源码头中的兼容性说明。

## 平台兼容性

- 标准C程序可以在Windows、macOS和Linux的GNU GCC环境中编译运行。
- `conio.h`、`getch()`等接口属于Windows/MinGW识别内容，不是跨平台接口。
- 完整仓库验证以MinGW-w64 GCC 8.1为最低基线，并在Windows GitHub Actions中复验。
- 教材兼容代码可能保留旧接口，仅用于识别和学习，不应直接用于生产程序。
