# C语言程序设计课件

本课程共48学时，包括16次讲授课和8次上机课。讲授课使用可离线打开的交互式HTML，上机课提供完整实验任务单。

## 学生入口

- [课程安排](课程安排.md)：查看24次课的章节、主题和核心程序。
- [16次讲授课](讲授/README.md)：按顺序学习第1—10章内容。
- [8次上机课](上机/README.md)：完成编程任务并填写实验报告。
- [题库](../题库/README.md)：按题型或章节选择练习。
- [例程库](../例程/README.md)：查找并运行章节示例程序。
- [GNU GCC环境配置](../环境配置/README.md)：配置Windows、macOS或Linux学习环境。

## 上机课

学生在上机过程中编写、运行和调试程序，并把过程与结果填写到教师发放的实验报告模板。最终提交PDF格式实验报告至超星学习通，不提交源码或运行产物。

具体项目、已学章节和任务单入口见[上机课索引](上机/README.md)。
