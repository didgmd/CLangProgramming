# 上机课

共8次上机课、16学时。每次2课时、90分钟，使用VS Code和GNU GCC独立完成1道编程题。

学生在上机过程中完成程序编写、运行、调试和结果记录，并将过程与结果填写到教师发放的实验报告模板。完成后的实验报告保存为PDF格式并提交至超星学习通；程序源码和运行产物不属于提交材料。

## 任务单使用方法

每份任务单依次包含实验项目、实验目的、实验步骤、打印分页和参考完整程序。先完成实验步骤和测试记录，再翻页对照参考程序。
