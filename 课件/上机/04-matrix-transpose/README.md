## 实验项目

三阶矩阵转置

## 实验目的

1. 掌握二维数组的声明、行列下标和嵌套遍历方法。
2. 掌握矩阵转置中原位置与目标位置的映射关系。
3. 提高嵌套循环程序的编写、运行和调试能力。

## 实验步骤

1. 阅读题目：输入一个3×3整数矩阵，将其转置后按行输出。样例输入`1 2 3 4 5 6 7 8 9`，样例输出三行为`1 4 7`、`2 5 8`、`3 6 9`。
2. 声明原矩阵和转置矩阵两个`int[3][3]`数组，使用`i`和`j`表示行列下标。
3. 写出位置映射`transpose[j][i] = matrix[i][j]`，确定两层循环的范围均为0至2。
4. 完成按行读取、位置转换和三行矩阵输出的程序。
5. 运行程序，观察一个元素如何从原矩阵第`i`行第`j`列移动到转置矩阵第`j`行第`i`列。
6. 使用下表逐项核对，并把矩阵结果填写到实验报告。

| 输入 | 预期输出 | 观察重点 |
|---|---|---|
| 1 2 3 4 5 6 7 8 9 | 1 4 7 / 2 5 8 / 3 6 9 | 顺序矩阵 |
| 1 2 3 2 4 5 3 5 6 | 1 2 3 / 2 4 5 / 3 5 6 | 对称矩阵 |
| -1 -2 -3 -4 -5 -6 -7 -8 -9 | -1 -4 -7 / -2 -5 -8 / -3 -6 -9 | 全负矩阵 |

## 参考完整程序

```c
#include <stdio.h>

int main(void)
{
    int matrix[3][3];
    int transpose[3][3];

    for (int i = 0; i < 3; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            scanf("%d", &matrix[i][j]);
        }
    }

    for (int i = 0; i < 3; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            transpose[j][i] = matrix[i][j];
        }
    }

    for (int i = 0; i < 3; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            printf("%d%c", transpose[i][j], j == 2 ? '\n' : ' ');
        }
    }

    return 0;
}
```
