## 实验项目

杨辉三角

## 实验目的

1. 掌握使用二维数组保存递推结果的方法。
2. 理解杨辉三角边界元素与内部元素的关系。
3. 能够核对不同规模下的递推结果和输出格式。

## 实验步骤

1. 阅读题目：输入行数`n`，其中`1≤n≤10`，输出杨辉三角的前`n`行。输入`4`时依次输出`1`、`1 1`、`1 2 1`和`1 3 3 1`。
2. 使用固定二维数组保存各项，声明行下标`i`、列下标`j`和行数`n`。
3. 将每行两端设置为1，内部元素使用`a[i][j] = a[i - 1][j - 1] + a[i - 1][j]`计算。
4. 按照读取行数、逐行计算和逐行输出的顺序完成程序。
5. 运行程序，观察边界元素与内部元素在各行中的形成过程。
6. 使用下表逐项核对，并把运行结果填写到实验报告。

| 输入 | 预期结果 | 观察重点 |
|---:|---|---|
| 1 | 仅输出`1` | 最小规模 |
| 4 | 第4行为`1 3 3 1` | 内部元素递推 |
| 7 | 第7行为`1 6 15 20 15 6 1` | 多行递推 |

## 参考完整程序

```c
#include <stdio.h>

int main(void)
{
    int n;
    long long a[10][10] = {{0}};

    scanf("%d", &n);

    for (int i = 0; i < n; i++)
    {
        a[i][0] = 1;
        a[i][i] = 1;

        for (int j = 1; j < i; j++)
        {
            a[i][j] = a[i - 1][j - 1] + a[i - 1][j];
        }
    }

    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j <= i; j++)
        {
            printf("%lld%c", a[i][j], j == i ? '\n' : ' ');
        }
    }

    return 0;
}
```
