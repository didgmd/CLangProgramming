## 实验项目

数字字符串转换

## 实验目的

1. 理解数字字符与整数值之间的关系。
2. 掌握字符数组遍历和十进制数值逐位累加方法。
3. 能够正确处理正负号、前导零和零值。

## 实验步骤

1. 阅读题目：输入一个合法十进制字符串，字符串可以带一个正号或负号，将其转换成整数并输出。样例输入`-2048`，样例输出`-2048`。
2. 声明字符数组`char s[64]`以及下标、符号和累加值变量，使用`scanf("%63s", s)`读取字符串。
3. 根据首字符确定符号和数字起点，并使用`value = value * 10 + s[i] - '0'`完成逐位转换。
4. 按照读取、判断符号、遍历数字字符和输出结果的顺序完成程序。
5. 运行程序，观察下标、当前字符和累加值在每一轮中的变化。
6. 使用下表逐项核对，并把运行结果填写到实验报告。

| 输入 | 预期输出 | 观察重点 |
|---|---:|---|
| -2048 | -2048 | 负号与数值组合 |
| +17 | 17 | 显式正号 |
| 0012 | 12 | 前导零 |
| 0 | 0 | 零值 |

## 参考完整程序

```c
#include <stdio.h>

int main(void)
{
    char s[64];
    int i = 0;
    int sign = 1;
    long long value = 0;

    scanf("%63s", s);

    if (s[i] == '+' || s[i] == '-')
    {
        if (s[i] == '-')
        {
            sign = -1;
        }
        i++;
    }

    while (s[i] != '\0')
    {
        value = value * 10 + s[i] - '0';
        i++;
    }

    printf("%lld\n", sign * value);
    return 0;
}
```
