02 · 数据保存

printf()与fprintf()的输出目标不同

标准输出

printf("Hello\n");

文字写到标准输出，通常显示在终端窗口中。

文件输出

fprintf(fp, "Hello\n");

文字按相同格式写入已打开的文件流fp。

fprintf()比printf()多一个文件流参数，用它指定输出目标。

16 · 完整程序

逐字符写入文本文件

#include <stdio.h>

int main()
{
    FILE *fp;
    int ch;

    fp = fopen("output.txt", "w");

    if (fp == NULL)
    {
        return 1;
    }

    ch = getchar();

    while (ch != '#' && ch != EOF)
    {
        fputc(ch, fp);
        ch = getchar();
    }

    fclose(fp);

    return 0;
}

输入约束：示例输入以#结束；浏览器仅模拟文件状态，不会创建真实文件。

23 · 读取一个字符

fgetc(in)返回字符值或EOF

读取成功

ch = fgetc(in);

ch保存当前字符的值，文件位置向后移动。

到达文件末尾

ch == EOF

没有新的字符可处理，复制循环结束。

24 · 返回值类型

ch使用int才能可靠区分字符和EOF

普通字符

fgetc()把无符号字符值转换为int返回。

文件结束

EOF是一个负的整数常量，不是文件中的普通字符。

int ch;
ch = fgetc(in);

先用int接收返回值，判断不是EOF后再把它作为字符处理。

30 · 完整程序

逐字符复制文本文件

#include <stdio.h>

int main()
{
    FILE *in;
    FILE *out;
    int ch;

    in = fopen("source.txt", "r");

    if (in == NULL)
    {
        printf("cannot open source\n");
        return 1;
    }

    out = fopen("copy.txt", "w");

    if (out == NULL)
    {
        fclose(in);
        printf("cannot open copy\n");
        return 1;
    }

    while ((ch = fgetc(in)) != EOF)
    {
        fputc(ch, out);
    }

    fclose(in);
    fclose(out);
    printf("copied\n");

    return 0;
}
