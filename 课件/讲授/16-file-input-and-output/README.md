## 试卷考点审计

8份本地历史试卷的只读核对表明，文件指针、`FILE *`定义、Windows路径转义、`fopen()`打开模式和逐字符写文件均曾出现。因此本课完整使用90分钟讲解文本文件顺序读写，不另设一般标准库函数专题。历史试卷原件保持只读、精确忽略且不进入Git。

## 两个教学段

前18页围绕`QB-FB-019`建立文件操作的基本顺序：声明文件流指针、以`"w"`模式打开、检查`NULL`、逐字符写入和关闭文件。后18页以`EX-C10-002`的规范化版本复制文本文件，重点比较`"r"`、`"w"`和`"a"`，直接检查`fgetc()`返回值、处理`EOF`并关闭两个文件流。

HTML共36页，包含5道完整选择题、1道程序填空题、两个逐字符执行器、8组确定性文件行为预演、错误诊断和课后自检。浏览器只维护虚拟文件状态，不访问学生电脑的真实文件系统。

## 内容边界

- 只讲文本文件和顺序字符读写。
- 历史试卷和稳定题库未出现`feof()`，学生课件不引入该函数，复制循环直接检查`fgetc()`返回值。
- 不讲二进制文件、随机访问、命令行参数、临时文件API或文件权限。
- `printf()`、`scanf()`、`fopen()`等统一称为标准库函数。
- `QB-PG-042`只保留为CW-LAB08待建题目，不是本讲授课的核心程序。
- `EX-C10-001`和`EX-C10-002`权威源码保持不变；课件中的程序用于规范化教学演示。
