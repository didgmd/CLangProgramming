## 两个教学段

1. 通过交换两个一级指针保存的地址，使其分别指向较大值和较小值，建立对象、地址、指针变量与解引用的关系。
2. 在字符数组中保留首指针并移动遍历指针，处理换行符与 `\0`，使用同一数组内的指针差计算字符串长度。

HTML共36页，包含两个逐步执行器、8组确定性状态预演、5道选择题、1道判断题、1道读程序题、两组错误诊断和两组课后自检。核心程序由校验器写入操作系统临时目录，使用MinGW GCC严格编译并执行5组行为测试后自动清理。

## 内容边界

- 正例只使用一级指针，不定义指针形参。
- 不讲二级指针、结构体、文件、动态内存、函数指针或多维数组指针。
- 指针参数、通过函数修改调用者数据和字符串复制留给 `CW-L13`。
- 地址图使用符号化位置，不展示或比较真实机器地址。
- 指针相减只讨论同一数组内的合法位置。
