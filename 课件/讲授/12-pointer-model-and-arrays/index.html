任务

输入两个整数。让两个指针分别指向这两个整数；必要时交换两个指针保存的地址，使第一个指针指向较大值，第二个指针指向较小值。

输入：两个整数，以空格分隔。

输出：max=较大值 min=较小值

样例

输入：5 8
输出：max=8 min=5

15 · 完整程序

交换指针指向，输出较大值和较小值

#include <stdio.h>

int main()
{
    int a, b;
    int *p1, *p2, *temp;

    scanf("%d %d", &a, &b);

    p1 = &a;
    p2 = &b;

    if (*p1 < *p2)
    {
        temp = p1;
        p1 = p2;
        p2 = temp;
    }

    printf("max=%d min=%d\n", *p1, *p2);

    return 0;
}

输入约束：两个输入均为合法整数。

30 · 完整程序

保留 start，只移动 p

#include <stdio.h>

int main()
{
    char s[] = "hello world\n";
    char *start;
    char *p;

    start = s;
    p = s;

    while (*p != '\0' && *p != '\n')
    {
        p++;
    }

    printf("%d\n", (int)(p - start));

    return 0;
}

本例直接初始化字符数组，重点观察指针移动和指针差；数组中包含的 \n 不计入长度。
