02 · 程序一

输出4行5列乘积表

任务

第 i 行、第 j 列输出乘积 i * j。

  • i 的范围：1至4
  • j 的范围：1至5
  • 每个数占4个字符宽度
  • 每完成一行输出一次换行

精确输出

   1   2   3   4   5
   2   4   6   8  10
   3   6   9  12  15
   4   8  12  16  20
03 · 行与列

两个循环变量承担不同职责

外层变量 i

决定当前输出第几行。

i = 1, 2, 3, 4

内层变量 j

决定当前行输出第几列。

j = 1, 2, 3, 4, 5
确定一行 i→遍历五列 j→换行→下一行
一个状态由有序对 (i, j) 表示。例如 (2, 4) 对应第2行第4列，输出8。
04 · 基本结构

内层 for 属于外层循环体

for (i = 1; i <= 4; i++)
{
    for (j = 1; j <= 5; j++)
    {
        printf("%4d", i * j);
    }

    printf("\n");
}
  1. 外层确定当前 i。
  2. 执行内层初始化 j = 1。
  3. 内层完成五次输出。
  4. 内层结束后执行换行。
  5. 外层执行 i++。
缩进和花括号清楚地表示归属关系：内层循环和换行语句都位于外层循环体中。
05 · 第一行

i = 1 时，j 完整变化一次

(1,1)1×1=1
(1,2)1×2=2
(1,3)1×3=3
(1,4)1×4=4
(1,5)1×5=5
j=1→输出1→j++→再次判断
当 j 更新为6时，条件 j <= 5 为假，第一行的内层循环结束。

08 · 执行次数

内层循环体共执行 4 × 5 次

4次外层循环
5次每行内层循环
20次乘法与数字输出
总次数 = 外层次数 × 每次外层对应的内层次数 = 4 × 5 = 20
printf("\n");不在内层循环中，所以执行4次，而不是20次。

09 · 完整程序

两层 for 输出乘积表

#include <stdio.h>

int main()
{
    int i, j;
    for (i = 1; i <= 4; i++)
    {
        for (j = 1; j <= 5; j++)
        {
            printf("%4d", i * j);
        }
        printf("\n");
    }
    return 0;
}
%4d表示整数至少占4个字符宽度，使各列对齐。

21 · 提前结束试除

找到因数后，只离开当前内层循环

n=105→i=2：不能整除→i=3：可以整除→break

结束的部分

105的试除循环立即结束，不再检查 i=4,5,...。

继续的部分

外层执行 n++，继续检查106。

break没有结束外层候选循环，也没有结束整个程序。
22 · 内层终止

试除循环有两个结束原因

i <= n / i

找到因数

n % i == 0

标志改为0，执行 break。

完成必要试除

i <= n / i变为假。

标志保持1，当前数是素数。

i <= n / i避免直接计算 i * i可能产生的溢出。

25 · 完整程序

输出100至200之间的素数

#include <stdio.h>

int main()
{
    int n, i;
    int is_prime;
    int count = 0;
    for (n = 100; n <= 200; n++)
    {
        is_prime = 1;
        for (i = 2; i <= n / i; i++)
        {
            if (n % i == 0)
            {
                is_prime = 0;
                break;
            }
        }
        if (is_prime)
        {
            if (count % 5 != 0)
            {
                printf(" ");
            }
            printf("%d", n);
            count++;
            if (count % 5 == 0)
            {
                printf("\n");
            }
        }
    }
    if (count % 5 != 0)
    {
        printf("\n");
    }
    return 0;
}
