## 选题审计

完整的选择排序和冒泡排序都需要保存一组数据，并且包含“多趟处理”和“每趟比较”两层迭代。用多个状态变量把两层迭代压入一个 while 虽然可以写出等价控制过程，但会掩盖算法本身的嵌套结构；单独执行一趟冒泡也不能保证排序完成。因此，排序留到数组知识建立后讲授。

当前题库中，不依赖数组或自定义函数的独立嵌套循环编程题只有 QB-PG-009。QB-PG-034 与其题面、区间和程序高度重复，且属于旧内容构造题，未作为第二个核心程序。本课前半使用教材例5.6 EX-C05-007 的规范化版本建立两层循环模型，后半完成 QB-PG-009。

## 两个教学段

### 前45分钟：4行5列乘积表

- 外层 i 控制行，内层 j 控制列。
- 每次进入内层 for 时，初始化表达式重新执行。
- 20个 (i,j) 状态与 4×5 执行次数。
- break 只结束直接包围它的内层循环。
- continue 跳过当前内层迭代的剩余语句。

课件采用补全花括号、去除额外计数器的规范化版本；EX-C05-007 权威源码保持不变。

### 后45分钟：输出区间素数

- 外层循环产生100至200的候选整数。
- 内层循环对当前候选数进行试除。
- 每个候选数开始时重置 is_prime。
- 发现因数后使用 break 结束当前试除。
- 使用 count 控制每行5个的输出格式。

## 内容边界

本课不引入数组、自定义函数、排序、矩阵、杨辉三角、筛法、递归、指针或 goto。continue 只作为乘积表的局部演示；两个核心程序的循环嵌套深度均为2。
