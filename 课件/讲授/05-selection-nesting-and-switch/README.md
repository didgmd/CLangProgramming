## 学习内容

前45分钟以一元二次方程题为主线，使用判别式和 `if / else if / else` 处理两个实根、重根和共轭复根，并用数学公式与C表达式逐项对照。后45分钟以成绩等级为主线，讲解 `switch`、`case`、`break`、`default` 及贯穿。嵌套分支及 `else` 归属通过两道读程序题专门训练。

课件共26页，方程部分将标准形式与判别式合并讲解，并以三结果表替代重复的独立决策树；全课包含两个逐步执行器、两道读程序题、一道选择题、8组确定性测试和两组七项课后自检。题干、公式、程序、选项和解析均直接显示，支持离线课堂演示与课后复习。

## 内容边界

- 正例不使用循环、数组、自定义函数或条件运算符。
- 学生程序采用题目保证输入格式合法的简化 `scanf()`；题库参考答案继续保留严格输入检查。
- `break` 只讲解其结束当前 `switch` 的作用，不扩展到循环控制。
- `EX-C04-008` 权威源码保持不变；课件按其原始输入输出契约展示。
