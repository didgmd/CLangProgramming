题目

输入一元二次方程的三个实数系数，分别处理两个实根、重根和共轭复根。

输入格式

输出格式

03 · 标准形式与判别式

由系数计算 Δ，判断根的类型

标准形式

ax2 + bx + c = 0，a ≠ 0

a 是二次项系数，b 是一次项系数，c 是常数项。

判别式

Δ = b2 − 4ac

Δ 的正、零、负分别对应两个实根、重根和共轭复根。

a b c判别式计算结果

1 2 14 − 4 = 0Δ = 0
1 2 54 − 20 = −16Δ < 0
04 · 求根公式

三种结果使用不同形式

Δ > 0：两个实根

x1,2 = −b ± √Δ2a

Δ = 0：重根

x = −b2a

Δ < 0：共轭复根

x1,2 = −b2a ± √(−Δ)|2a|i

06 · 从公式到C表达式

数学符号需要转换为运算符和函数

Δ = b2 − 4ac
d = b * b - 4.0 * a * c;
x1 = −b + √Δ2a
x1 = (-b + sqrt(d)) / (2.0 * a);

转换规则

  • b2 写成 b * b。
  • 省略的乘号必须写成 *。
  • 根号使用 sqrt()。
  • 分子和分母分别使用括号。
07 · 多分支

if / else if / else：互斥路径

if (d > 1e-12)
{
    /* 两个实根 */
}
else if (fabs(d) <= 1e-12)
{
    /* 重根 */
}
else
{
    /* 复根 */
}

执行规则

  1. 从上到下检查条件。
  2. 执行第一个成立的分支。
  3. 该分支结束后，跳过其余分支。
  4. 前面条件都不成立时执行 else。
三个分支互斥，一次只执行其中一个。
08 · 完整程序

按判别式处理三种结果

#include <math.h>
#include <stdio.h>

int main()
{
    double a, b, c, d, x1, x2;
    double real_part, imag_part;
    /* 输入、判别式和两个实根 */
    scanf("%lf %lf %lf", &a, &b, &c);
    d = b * b - 4.0 * a * c;
    if (d > 1e-12)
    {
        x1 = (-b + sqrt(d)) / (2.0 * a);
        x2 = (-b - sqrt(d)) / (2.0 * a);
        printf("%.6f %.6f\n", x1, x2);
    }
    /* 重根、复根和程序结束 */
    else if (fabs(d) <= 1e-12)
    {
        printf("%.6f\n", -b / (2.0 * a));
    }
    else
    {
        real_part = -b / (2.0 * a);
        imag_part = sqrt(-d) / fabs(2.0 * a);
        printf("%.6f+%.6fi %.6f-%.6fi\n",
            real_part, imag_part, real_part, imag_part);
    }
    return 0;
}

14 · 固定离散值

多个相等判断可以写成 switch

if (grade == 'A')
{
    /* A的处理 */
}
else if (grade == 'B')
{
    /* B的处理 */
}
switch (grade)
{
case 'A':
    /* A的处理 */
    break;
case 'B':
    /* B的处理 */
    break;
}
switch 适合把一个表达式的结果与多个固定、离散的常量比较。

范围判断、浮点近似判断或复杂逻辑条件仍应使用 if。

15 · 基本结构

switch、case、break 与 default

switch (表达式)
{
case 常量1:
    语句;
    break;
case 常量2:
    语句;
    break;
default:
    语句;
}
  • switch：计算一次表达式。
  • case：标记一个固定匹配值。
  • break：立即离开当前 switch。
  • default：没有任何 case 匹配时执行。

17 · 匹配过程

先计算表达式，再跳到匹配位置

不会从A开始逐条判断

case本身不是条件表达式

它只是程序中的匹配入口。

匹配后顺序执行

直到遇到 break 或离开结构。

18 · break

break 防止继续进入后续 case

case 'B':
    printf("70～84\n");
    break;
case 'C':
    printf("60～69\n");
    break;

输入 B 时

  1. 跳到 case 'B'。
  2. 输出 70～84。
  3. 执行 break。
  4. 离开整个 switch。
这里的 break 只用于结束当前 switch；本课不讨论循环中的 break。
19 · default

没有 case 匹配时执行 default

default:
    printf("enter data error!\n");

输入 X 时，A、B、C、D 均不匹配，因此执行此处。

规则

  • default 可以省略。
  • 本程序保留它，用于处理未列出的等级。
  • 通常放在全部 case 之后，便于阅读。

24 · 贯穿过程

没有 break：从入口继续向下执行

i = 10;
switch (i)
{
case 10:
    i++;
case 11:
    i++;
default:
    i++;
}
初始 i = 10。依次点击三个执行位置。
贯穿不是重新进行匹配，而是从已匹配的入口继续顺序执行后续语句。
