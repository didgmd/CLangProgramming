03 · 选择排序

每一趟确定一个位置

查找

在尚未确定的记录中找到最高成绩。

记住

用下标k保存最高成绩记录的位置。

交换

查找结束后，把完整记录放到当前起始位置。

降序选择排序从左向右逐个确定最高成绩记录。

04 · 两种排序过程

冒泡排序与选择排序的交换时机不同

方法一趟中的比较交换方式一趟结束后
冒泡排序反复比较相邻记录一趟中可能多次交换一条记录到达末端
选择排序查找未确定区间中的最高成绩查找结束后交换一次一条记录到达左端

本课只改变排序过程；结构体记录和整体交换规则与上一课相同。

05 · 三个下标

i、j和k承担不同职责

06 · 初始化最高下标

每一趟都从k = i开始

for (i = 0; i < 4; i++)
{
    k = i;
    /* 从 i 后面继续查找 */
}

第0趟

i=0，先令k=0。

第1趟

i=1，必须重新令k=1。

k只表示本趟尚未确定区间中的最高成绩位置。

07 · 第一趟查找

只更新最高成绩下标，不立即交换

初始状态：i=0，k=0，当前最高成绩为82.0。
08 · 查找阶段

发现更高成绩时只执行k = j

for (j = i + 1; j < 5; j++)
{
    if (students[j].score > students[k].score)
    {
        k = j;
    }
}

比较的是成绩成员，保存的是整条记录的下标。

若在内层循环中立即交换，程序就不再是这里讲解的选择排序过程。

09 · 整体交换

查找结束后交换两条完整记录

temp = students[i];
students[i] = students[k];
students[k] = temp;
students[i]
1 / 82.0
⇄
students[k]
3 / 90.0

结构体整体赋值会同时移动学号和成绩，二者不会错配。

13 · 完整程序

结构体数组选择排序

#include <stdio.h>
struct Student
{
    int id;
    double score;
};
int main()
{
    struct Student students[5];
    struct Student temp;
    int i, j, k;
    for (i = 0; i < 5; i++)
    {
        scanf("%d %lf", &students[i].id, &students[i].score);
    }
    for (i = 0; i < 4; i++)
    {
        k = i;
        for (j = i + 1; j < 5; j++)
        {
            if (students[j].score > students[k].score)
            {
                k = j;
            }
        }
        temp = students[i];
        students[i] = students[k];
        students[k] = temp;
    }
    for (i = 0; i < 5; i++)
    {
        printf("%d %.1f\n", students[i].id, students[i].score);
    }
    return 0;
}

输入约束：5组学号和成绩均符合题目规定格式。

23 · 点号与箭头

左侧对象不同，成员访问形式不同

结构体变量

s.id
s.score
s.name

使用点运算符.。

结构体指针

p->id
p->score
p->name

使用箭头运算符->。

24 · 两种等价形式

p->id等价于(*p).id

p->id

直接通过结构体指针访问成员。

(*p).id

先用*p得到所指结构体，再使用点号。

*p必须加括号。*p.id会先尝试计算p.id，但p是指针，不能使用点号。
