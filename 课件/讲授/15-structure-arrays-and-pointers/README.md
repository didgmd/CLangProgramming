## 核心知识点

结构体数组、整体交换、结构体指针、排序

CW-L14已介绍固定长度结构体数组和完整记录交换。本课将在此基础上使用选择排序，并重点讲解结构体指针和指针方式的成员访问。

## 本课目标

能保持记录字段同步，对结构体数组排序并解释成员访问形式。

## 内容边界

本课不讲：不讲动态链表和大型信息管理项目。
