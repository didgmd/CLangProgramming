## 核心知识点

结构体数组选择排序、最高成绩下标、结构体整体交换、结构体变量地址、结构体指针、`.`与`->`成员访问、字符指针成员及字符串位置表达式。

## 两个教学程序

1. 前45分钟完成 `QB-PG-031`，每趟在未确定记录中查找最高成绩下标，再交换完整学生记录。
2. 后45分钟分析 `QB-TR-012`，逐步推导 `*p->name`、`&p->name[2]`及精确输出 `W,ng`。

课件共35页，包含选择排序第一趟与全部趟数执行器、结构体记录状态表、两道完整选择题、结构体变量—指针—成员关系图、字符位置带、表达式执行器、确定性测试、错误诊断和课后自检。

## 选题与内容边界

- CW-L14已经讲解固定长度结构体数组、冒泡排序和完整记录交换；本课改用选择排序，并重点建立结构体指针的成员访问规则。
- 两个核心例题均来自现有往年题库，不增加新的题目ID。
- `QB-TR-012`中的字符指针成员只用于理解已有表达式，不扩展到字符串库、动态字符串或内存管理。
- 本课不使用文件API、链表、动态内存、二级指针、函数指针、结构体指针参数、`typedef`、联合体或枚举。
- 学生排序程序假设输入格式合法；浏览器中的执行过程为确定性模拟，不是真实C编译。
- 文件输入输出继续由CW-L16单独讲授。
