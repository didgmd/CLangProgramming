## 核心知识点

前半段以求两个整数较大值建立函数声明、调用、定义、实参、形参、按值传递和返回值模型；后半段以10个浮点数排序建立`void`函数、数组参数、长度参数及主函数与子函数的任务分工。

## 两个核心程序

1. `EX-C07-002`：输入两个整数，调用`max`函数返回较大值。
2. `QB-PG-013`：输入10个浮点数，调用`sort`子函数升序输出。

34页课件包含实与形参映射、按值传递、函数定义位置和返回路径演示，两道完整程序填空题，两组函数执行器，6组确定性程序预演、错误诊断和课后自检。浏览器只模拟确定性状态；两个学生版程序由校验器在操作系统临时目录中用MinGW GCC严格编译、执行并清理。

## 内容边界

- 数组参数只讲调用后可观察的数组元素变化，不展开底层机制。
- 不使用递归、指针变量、全局变量、函数指针、动态内存或多文件函数。
- 排序算法沿用CW-L08已学的冒泡排序，本课聚焦函数接口与调用过程。
- `EX-C07-002`和`EX-C07-012`权威源码保持不变。
