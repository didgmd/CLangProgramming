存放位置

scanf()为什么需要 &

故意错误示例

int score;
scanf("%d", score);

第二个参数没有提供变量的存放位置。

正确示例

int score;scanf("%d", &score);

&score 表示 score 的存放位置。

输入约束：示例只处理合法整数。完整的地址与指针知识将在后续内容中展开。
格式、类型和分隔方式

输入语句必须匹配数据形式

故意错误：类型不匹配

double average;
scanf("%d", &average);

故意错误：分隔方式不一致

实际输入：80 90 70

int a, b, c;
scanf("%d,%d,%d", &a, &b, &c);
空白分隔

80 90 70 可由 "%d%d%d" 或 "%d %d %d" 读取。

逗号分隔

80,90,70 对应 "%d,%d,%d"，逗号必须实际出现。

%d会自动跳过输入前的空格、Tab和换行；格式串中的空格主要用于清晰表示输入项。变量是否需要赋值取决于后续是否使用，与声明数量无关。
