## 核心知识点

常量、变量、初始化、基本类型、字符与字符串、`printf()`格式说明符、`scanf()`输入。

算法只作为“把题目拆成可执行步骤”的桥梁；页面使用伪代码和程序顺序，不安排独立算法题。

## 学生学习目标

学生能够：

- 区分常量、变量、初始化和赋值；
- 在 `int`、`double`、`char` 中选择合适类型；
- 匹配 `%d`、`%f`、`%.2f`、`%c` 和 `\n`；
- 解释 `scanf("%d", &score);` 的格式串和存放位置；
- 根据程序预测输出，并完成三门成绩总分与平均分程序。

## 内容边界与输入约束

本课只把算法用于整理执行步骤，不展开算法复杂度、循环、数组、函数参数和完整指针理论。

正例不使用 `if` 或 `scanf()` 返回值检查，统一采用题目保证输入合法的前提。
这种写法用于初学和考试题理解，不等同于生产程序的输入安全规范。
