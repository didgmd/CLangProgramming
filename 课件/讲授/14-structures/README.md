## 核心知识点

结构体类型、结构体变量、成员访问、结构体初始化、记录输入输出、固定长度结构体数组、结构体整体赋值和整条记录交换。

## 两个教学程序

1. 前45分钟使用教材例9.2 `EX-C09-002`的规范化版本，比较两名学生的成绩并输出成绩较高的完整记录。
2. 后45分钟完成 `QB-PG-030`，按成绩降序排列5条学生记录，并保持学号与成绩的对应关系。

课件共36页，包含结构体类型—变量—成员关系图、成员访问练习、三路径记录比较执行器、结构体数组状态表、整条记录交换演示、冒泡排序执行器、7组确定性程序预演和两组课后自检。

## 选题与内容边界

- 第9章往年编程题 `QB-PG-030` 与 `QB-PG-031` 均为结构体记录排序；本课使用冒泡排序题，选择排序题保留给 `CW-L15`。
- `QB-SC-026`、`QB-SC-027`和`QB-TR-012`包含结构体指针相关语法，本课不展示。
- 本课只使用结构体变量、成员和固定长度结构体数组，不讲结构体指针、`->`、链表、文件、动态内存、`typedef`、联合体、枚举或嵌套结构体。
- `char name[20]`只用于说明数组可以作为结构体成员，不扩展字符串库函数。
- 学生程序假设输入格式合法；浏览器中的执行过程为确定性模拟，不是真实C编译。
