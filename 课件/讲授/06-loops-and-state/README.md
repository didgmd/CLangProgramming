## 学习内容

前45分钟以判断素数为主线，使用单层 `while` 说明初始化、循环条件、状态变量、循环更新和自然终止。后45分钟以输出全部三位水仙花数为主线，使用单层 `for` 说明枚举范围、循环变量、数位分解和条件输出。`do-while` 只通过初始条件为假时的对比说明“至少执行一次”。

课件共28页，包含两个完整程序、一个读程序题、两道选择题、两个逐步执行器、5组素数测试、水仙花数完整输出验证及两组七项课后自检。题干、程序、选项和解析均直接显示，支持离线课堂演示与课后复习。

## 排序算法的课次边界

本课不使用选择排序或冒泡排序。完整排序需要数组保存多个数据；标准选择排序和冒泡排序还包含“多趟处理”和“每趟比较”两层迭代。虽然可以把两层状态压入一个 `while`，但算法本质仍是双层迭代，代码反而更难理解；单独执行一趟冒泡也不能保证完成排序。排序保留到数组和嵌套循环均已讲授后处理。
