06 · while

先判断条件，再执行循环体

初始化;

while (条件)
{
    循环体;
    更新;
}
初始化→判断条件→执行→更新
  1. 初始化只执行一次。
  2. 每一轮开始前都检查条件。
  3. 条件为真才进入循环体。
  4. 更新必须让程序逐步接近结束。

07 · 循环条件

两个条件同时成立才继续试除

is_prime && i <= n / i

is_prime

值为1：还没有发现因数，可以继续。

值为0：已经确定不是素数，循环结束。

i <= n / i

当前试除数仍在需要检查的范围内。

超过范围：所有必要的试除已经完成。

循环有两种结束原因：发现因数，或者完成全部必要试除。

09 · while 与 do-while

初始条件为假时，执行次数不同

while：先判断

int i = 5;
while (i < 5)
{
    printf("%d\n", i);
    i++;
}

循环体执行0次。

do-while：先执行

int i = 5;
do
{
    printf("%d\n", i);
    i++;
} while (i < 5);

do-while 先输出5，再执行 i++，最后判断条件；循环体执行1次，末尾必须有分号。

10 · 完整程序

使用 while 和状态变量判断素数

#include <stdio.h>

int main()
{
    int n;
    int i = 2;
    int is_prime = 1;

    scanf("%d", &n);
    if (n < 2)
    {
        is_prime = 0;
    }
    while (is_prime && i <= n / i)
    {
        if (n % i == 0)
        {
            is_prime = 0;
        }

        i++;
    }
    if (is_prime)
    {
        printf("prime\n");
    }
    else
    {
        printf("not prime\n");
    }
    return 0;
}

23 · 判断表达式

C语言没有用 ^ 表示乘方

错误写法

sum = hundreds ^ 3
    + tens ^ 3
    + ones ^ 3;

^是按位异或运算符。

正确写法

sum = hundreds * hundreds * hundreds
    + tens * tens * tens
    + ones * ones * ones;
if (sum == n) → 输出当前 n
24 · 完整程序

使用单层 for 枚举三位数

#include <stdio.h>

int main()
{
    int n;
    int hundreds, tens, ones;
    int sum;
    for (n = 100; n <= 999; n++)
    {
        hundreds = n / 100;
        tens = n / 10 % 10;
        ones = n % 10;
        sum = hundreds * hundreds * hundreds
            + tens * tens * tens
            + ones * ones * ones;
        if (sum == n)
        {
            printf("%d\n", n);
        }
    }
    return 0;
}
