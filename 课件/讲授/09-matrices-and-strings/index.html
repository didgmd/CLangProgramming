03 · 基本过程

每一趟确定当前位置的最小元素

1. 划分区域

2. 寻找最小值

3. 完成交换

一趟查找结束后，与当前起始位置交换。

07 · 下标初值

每一趟都要重新执行 k = i

第0趟

i = 0，k = 0

先把a[0]看作未排序部分的最小值。

第3趟

i = 3，k = 3

前三个位置已确定，从a[3]重新开始。

如果不重新设置k，它可能仍指向已经确定的左侧区域。
08 · 交换时机

先找完整趟的最小下标，再交换一次

内层循环

if (a[j] < a[k])
{
    k = j;
}

只改变k。

内层循环结束

t = a[i];
a[i] = a[k];
a[k] = t;

只交换一次。

下标记录把“寻找最小值”和“移动元素”分成两个清晰步骤。

12 · 完整程序

十个整数选择排序

#include <stdio.h>

int main()
{
    int a[10];
    int i, j, k, t;

    for (i = 0; i < 10; i++)
    {
        scanf("%d", &a[i]);
    }

    for (i = 0; i < 9; i++)
    {
        k = i;

        for (j = i + 1; j < 10; j++)
        {
            if (a[j] < a[k])
            {
                k = j;
            }
        }

        t = a[i];
        a[i] = a[k];
        a[k] = t;
    }

    for (i = 0; i < 10; i++)
    {
        if (i > 0)
        {
            printf(" ");
        }

        printf("%d", a[i]);
    }

    printf("\n");
    return 0;
}
输入约束：程序运行时提供恰好10个合法整数。

26 · 完整程序

3行4列矩阵的最大元素及位置

#include <stdio.h>

int main()
{
    int a[3][4];
    int i, j;
    int maximum;
    int row, column;

    for (i = 0; i < 3; i++)
    {
        for (j = 0; j < 4; j++)
        {
            scanf("%d", &a[i][j]);
        }
    }

    maximum = a[0][0];
    row = 0;
    column = 0;

    for (i = 0; i < 3; i++)
    {
        for (j = 0; j < 4; j++)
        {
            if (a[i][j] > maximum)
            {
                maximum = a[i][j];
                row = i;
                column = j;
            }
        }
    }

    printf("%d %d %d\n", maximum, row, column);
    return 0;
}
输入约束：程序运行时按行提供12个合法整数。
