## 核心知识点

前半段以选择排序建立“当前位置、检查位置、最小元素下标”的状态模型。中段以 3 行 4 列矩阵建立行列下标、嵌套遍历、最大值与位置同步更新的模型。字符串部分先用两页介绍字符数组的结束规则和常用函数，再练习长度转换、字符串拼接和二维字符数组的后缀输出。

## 两个核心程序

1. `QB-PG-008`：10个整数选择排序，覆盖`k=i`、未排序区间、趟末交换和9趟状态。
2. `QB-PG-010`：3行4列矩阵最大值，覆盖二维数组声明、行列边界、首元素初始化和位置同步更新。

37 页课件包含两个逐步执行器、完整真题、6 组确定性程序预演、字符串函数练习、二维字符数组读程序题、错误诊断和课后自检。浏览器模拟程序状态。校验器将两个学生版程序写入临时目录，用 MinGW GCC 严格编译并执行后立即清理。
