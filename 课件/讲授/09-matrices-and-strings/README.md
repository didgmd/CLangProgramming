## 核心知识点

前半段以选择排序建立“当前位置、检查位置、最小元素下标”的状态模型；后半段以3行4列矩阵建立行列下标、嵌套遍历、最大值与位置同步更新的模型。末尾使用字符方格和下标遍历说明字符数组、C字符串、`\0`、`\n`和字符`'0'`的区别。

## 两个核心程序

1. `QB-PG-008`：10个整数选择排序，覆盖`k=i`、未排序区间、趟末交换和9趟状态。
2. `QB-PG-010`：3行4列矩阵最大值，覆盖二维数组声明、行列边界、首元素初始化和位置同步更新。

34页课件包含两个逐步执行器、完整真题、6组确定性程序预演、错误诊断和课后自检。浏览器只模拟确定性状态；两个学生版程序由校验器写入操作系统临时目录，用MinGW GCC严格编译并执行后立即清理。

## 内容边界

- 字符串只建立基础存储与结束模型，不设置第三个完整程序。
- 不使用字符串输入、`string.h`或字符串库函数。
- 不引入自定义函数、递归、指针变量、数组参数、矩阵转置或二维字符数组。
- `EX-C06-005`和`EX-C06-006`仅作为课后稳定引用，权威源码保持不变。
