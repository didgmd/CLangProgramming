## 两个教学段

前45分钟使用`EX-C04-002`讲解关系表达式、C语言真值、单分支`if`和临时变量交换。课件将教材例程的输入输出规范化为空白分隔输入和两位小数输出，不修改例程权威源码。

后45分钟使用`QB-PG-003`讲解整除条件、`&&`、`||`和显式`if/else`，按照公历规则判断闰年。输入均由题目保证格式合法。
