06 · 单分支

if：条件为真时执行一个程序块

语法条件 → 程序块
if (条件){    条件为真时执行的语句;}后续语句;
条件为真

执行花括号中的语句，再执行后续语句。

条件为假

跳过花括号中的语句，直接执行后续语句。

18 · 逻辑或与括号

||：两种闰年情况满足一种即可

year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)
第一种情况

能被400整除。

year % 400 == 0
第二种情况

能被4整除，并且不能被100整除。

(year % 4 == 0 && year % 100 != 0)
括号把第二种情况组织成一个整体，使条件结构一目了然。

{
    语句A;
}

条件为假

    语句B;
}
