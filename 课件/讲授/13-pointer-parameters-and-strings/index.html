    * b = t;

03 · 参数传递对比

普通参数传数值，指针参数传地址

普通参数：修改副本

void change_value(int a)
{
    a = 9;
}

int x = 3;
change_value(x);
/* x仍为3 */

形参a获得数值3的副本；修改a不会修改x。

指针参数：修改所指对象

void change_object(int *p)
{
    *p = 9;
}

int x = 3;
change_object(&x);
/* x变为9 */

形参p获得&x的副本；*p仍访问并修改x。

两种调用都按值传递；区别在于被复制的是普通数值还是对象地址。

07 · 地址也按值传递

形参保存地址副本，解引用仍访问原对象

形参本身

a和b是函数调用期间建立的局部变量，保存地址副本。

所指对象

*a和*b访问调用者的x和y。

交换a、b只改变局部地址副本；交换*a、*b才会修改调用者对象。

11 · 完整程序

通过指针形参交换调用者数据

#include <stdio.h>

void swap(int *a, int *b);

int main()
{
    int x = 3;
    int y = 8;

    swap(&x, &y);
    printf("%d %d\n", x, y);

    return 0;
}

void swap(int *a, int *b)
{
    int t;

    t = *a;
    *a = *b;
    *b = t;
}

26 · 同步移动

两个指针都要移到下一位置

to++;

只移动一个指针会重复读取或覆盖同一目标位置。

28 · 循环条件

结束符不在循环体中复制

while (*from != '\0')
{
    *to = *from;
    from++;
    to++;
}

条件为真

当前位置是可见字符，复制并移动。

条件为假

当前位置是\0，立即离开循环。

31 · 完整程序

字符指针形参逐字符复制

#include <stdio.h>

void copy_string(char *from, char *to);

int main()
{
    char source[80];
    char destination[80];

    scanf("%79s", source);
    copy_string(source, destination);
    printf("%s\n", destination);

    return 0;
}

void copy_string(char *from, char *to)
{
    while (*from != '\0')
    {
        *to = *from;
        from++;
        to++;
    }

    *to = '\0';
}

输入约束：字符串长度不超过79且不含空白字符。
