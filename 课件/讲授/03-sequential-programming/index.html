四位数各位立方和

编程题

输入四位正整数，求各位数字立方和。

输入格式

一个四位正整数。

输出格式

输出四个数位的立方和。

数据范围：1000至9999。

样例

输入：1234 输出：100

1³ + 2³ + 3³ + 4³ = 100

输入约束：程序接收一个符合范围要求的四位正整数。

1

程序的任务不是把数字当作字符串切开，而是利用整数运算得到每个数位。
整数除法

/可以去掉右侧低位

1234 / 10

123

去掉个位。

1234 / 100

12

1234 / 1000

1

规则：两个整数相除，结果仍是整数，小数部分直接舍去。

取余运算

%可以保留右侧低位

1234 % 10

4

保留个位。

1234 % 100

34

保留后两位。

1234 % 1000

234

保留后三位。

1234 = 123 × 10 + 4
%计算整数除法的余数，两个操作数必须是整数类型。

表达式组合

四个数位分别怎样得到？

千位

thousands = n / 1000;

去掉右侧三位。

百位

hundreds = n / 100 % 10;

先去掉两位，再保留个位。

十位

tens = n / 10 % 10;

先去掉一位，再保留个位。

个位

ones = n % 10;

直接取得除10的余数。

/和%优先级相同，按从左到右的顺序计算。

立方和

C语言用连续乘法表示立方

正确表达式

d × d × d
d * d * d

故意错误

d ^ 3

^是按位异或运算符，不是乘方符号。

C语言没有直接写成立方的运算符；本题使用三次乘法最清楚。

教材例3.4 · 海伦公式

已知三边，求三角形面积

已知能够组成三角形的三条边 a、b、c。先计算半周长 s，再使用海伦公式计算面积 S。

s = a + b + c2
S = √s(s − a)(s − b)(s − c)
样例输入

3 4 5

样例输出

6.00

输入约束：三个正数能够组成有效三角形。本程序不负责判断边长是否合法。
公式中的量

每个符号都对应一个变量

C变量区分大小写。程序用变量名 area 保存数学公式中的面积 S。
QB-SC-059 · 格式说明符

读取double变量

读取 double 变量应使用的 scanf 格式说明符是（ ）。

第一步 · 半周长

先计算 s

s = a + b + c2
C表达式使用浮点除法
s = (a + b + c) / 2.0;
a3.0
b4.0
c5.0
s = (3 + 4 + 5) / 2.0 = 6.0
面积公式中的四个因子

把海伦公式逐项计算

s(s − a)(s − b)(s − c) = 6 × 3 × 2 × 1 = 36
平方根函数

sqrt()来自math.h

头文件提供数学函数声明
#include <math.h>area = sqrt(36.0);
√36 = 6

sqrt(x)计算非负数 x 的平方根，结果为浮点数。

本课只使用已有的标准库函数，不展开函数定义和参数机制。
从公式到C表达式

海伦公式的完整转换

S = √s(s − a)(s − b)(s − c)
C表达式每一对括号都对应公式中的一项
area = sqrt(s * (s - a) * (s - b) * (s - c));
减法先算

括号保证先得到每个差值。

再做乘法

四个因子依次相乘。

最后开方

乘积作为 sqrt() 的参数。

格式化输出

面积保留两位小数

输出语句double由printf的%f输出
printf("%.2f\n", area);
area实际值9.902...
屏幕输出9.90

.2规定小数点后显示两位，输出时会按规则舍入。

scanf()读取 double 使用 %lf；printf()输出 double 使用 %f。
