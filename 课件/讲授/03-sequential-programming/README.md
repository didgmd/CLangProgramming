## 核心知识点

顺序结构、整数除法、取余、数位分解、`double`、`%lf`、`%.2f`、海伦公式、`sqrt()`。

## 两个教学段

1. 前45分钟以“四位数各位立方和”为主线，使用整数除法和取余提取千位、百位、十位和个位，再按顺序计算立方和。
2. 后45分钟以教材例3.4为主线，显式讲解海伦公式
   `s=(a+b+c)/2`、`S=sqrt(s(s-a)(s-b)(s-c))`，并将公式转换为C表达式。

HTML共25页，完整展示三道关联习题、两个逐行执行器、六组确定性测试、错误诊断和课后自检，可离线用于课堂投影和学生复习。

## 输入与内容边界

- 四位数程序接收1000至9999的合法整数。
- 三角形程序接收能够组成有效三角形的三个正数。
- 正例只使用声明、输入、计算和输出，不引入条件、循环、数组、自定义函数或输入返回值检查。
- `sqrt()`只作为标准库函数使用，不展开自定义函数知识。
