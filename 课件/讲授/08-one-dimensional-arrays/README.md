## 选题审计

当前历年真题中，QB-PG-002适合建立数组、下标、遍历和最大值状态模型；QB-PG-004在此基础上引入相邻比较、交换和两层循环。QB-PG-008选择排序与第二题输入输出接近，本课不同时讲授两种排序方法，避免削弱冒泡排序主线。

## 两个教学段

### 前45分钟：十个实数中的最大值

- 声明、初始化和访问固定长度一维数组。
- 明确长度10的有效下标为0至9。
- 使用循环保存并遍历十个实数。
- 以a[0]初始化maximum，正确处理全负数和重复最大值。
- 使用%.6f输出最大值。

### 后45分钟：十个整数冒泡排序

- 比较相邻的a[i]和a[i+1]。
- 使用临时变量交换两个元素。
- 观察第一趟如何把最大元素移动到末尾。
- 使用i < 9 - j缩小每一趟的比较范围。
- 通过逆序、已有序和重复值数据验证结果。

## 内容边界

本课只使用固定长度的一维数值数组，不引入二维数组、字符数组、字符串、自定义函数、数组参数、指针理论、变长数组、动态数组、选择排序或复杂度分析。scanf中的&a[i]只解释为当前元素的存放位置。
