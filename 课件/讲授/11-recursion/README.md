## 学生端内容

34页离线HTML分为两个教学段：前17页以递归阶乘建立“出口—展开—返回”的单链递归模型；后17页以斐波那契数列说明两个出口、双分支递归树和返回值组合。题目、选项、程序、测试与答案解释均直接显示，支持课堂演示和课后重复操作。

## 核心知识点

- 递归出口、递归关系和参数向出口靠近；
- 每次函数调用具有独立的形参状态；
- 递归展开与逐层返回；
- 单链递归与双分支递归；
- 用数学定义检查递归函数，并手工推导返回值。

## 内容边界

本课不使用指针、数组、结构体、文件或动态内存，不实现间接递归，不展开递归优化、缓存、复杂度、栈帧布局、尾递归、汉诺塔和回溯。斐波那契主程序中的循环只负责依次输出第0至第19项。
