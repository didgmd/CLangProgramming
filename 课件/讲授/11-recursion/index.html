04 · 三个必要部分

出口、规模缩小、结果组合

递归出口

能够直接给出结果，不再调用自身。

规模缩小

新实参比当前问题更接近出口。

结果组合

使用子问题的返回值构成当前结果。

factorial(n) = n × factorial(n - 1)
05 · 阶乘定义

数学定义直接给出递归结构

可以直接回答

0! = 1
1! = 1

转化为更小问题

n! = n × (n - 1)!　(n ≥ 2)

例如：5! = 5×4×3×2×1 = 120。

07 · 递归出口

n≤1同时覆盖0!和1!

当前n条件n≤1本层动作
0真直接返回1
1真直接返回1
2或更大假调用factorial(n-1)
出口必须在递归调用之前判断。
08 · 递归展开

factorial(5)逐层产生更小调用

factorial(5)
→
5 × factorial(4)
→
4 × factorial(3)
→
… × factorial(1)

展开阶段尚不能完成外层乘法；每一层都在等待下一层的返回值。

09 · 独立调用状态

每一层都有自己的形参n

第1层：n=5，等待factorial(4)
第2层：n=4，等待factorial(3)
第3层：n=3，等待factorial(2)
第4层：n=2，等待factorial(1)
第5层：n=1，直接返回1
内层的n不会覆盖外层保存的n。
10 · 逐层返回

到达出口后，乘法从内向外完成

factorial(1)=1
→
factorial(2)=2
→
factorial(3)=6
→
factorial(4)=24
→
factorial(5)=120
展开顺序是5→4→3→2→1，返回顺序正好相反。
11 · 完整程序

递归阶乘与输入范围

#include <stdio.h>

long long factorial(int n);

int main()
{
    int n;

    scanf("%d", &n);

    if (n < 0 || n > 20)
    {
        printf("invalid\n");
    }
    else
    {
        printf("%lld\n", factorial(n));
    }

    return 0;
}

long long factorial(int n)
{
    if (n <= 1)
    {
        return 1;
    }

    return n * factorial(n - 1);
}

26 · 完整程序

递归计算并输出前20项

#include <stdio.h>

int fibonacci(int n);

int main()
{
    int i;

    for (i = 0; i < 20; i++)
    {
        if (i > 0)
        {
            printf(" ");
        }

        printf("%d", fibonacci(i));
    }

    printf("\n");

    return 0;
}

int fibonacci(int n)
{
    if (n == 0)
    {
        return 0;
    }

    if (n == 1)
    {
        return 1;
    }

    return fibonacci(n - 1) + fibonacci(n - 2);
}
