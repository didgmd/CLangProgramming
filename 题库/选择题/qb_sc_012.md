# 数组定义

## 题目

下列数组定义中符合固定长度数组规则的是（ ）。

A. int a[-3];

B. int a[10];

C. int a[3,5];

D. int a[][];

## 常见失分点



本题考查“数组定义”（数组定义）。逐项代入C语言规则核对，尤其不要把看起来熟悉的写法直接当作合法答案。

<details>
<summary>参考答案与解析</summary>

**答案：B。**

固定长度必须为正整数常量表达式；其余选项的维数或长度不合法。

</details>
