# 字符串终止条件

## 题目

遍历 C 字符串最常用的结束条件是（ ）。

A. 遇到空格

B. 遇到换行

C. 遇到 '\0'

D. 达到整数 0 之外任意值

## 常见失分点

先判断语法和运算规则，再看选项；不要只凭代码外观猜测。

<details>
<summary>参考答案与解析</summary>

**答案：C。**

C 字符串以空字符 `\0` 作为结束标志。

</details>
